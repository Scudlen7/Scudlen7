# Hi, I’m [Scudlen](https://github.com/Scudlen7/) 👋

Welcome to my little corner of GitHub. I’m a “zero-stack” developer finding my way, one frontend experiment at a time.

## About me

I like open source, trying unfamiliar tools, and figuring out why something finally worked. My favorite test of whether I’ve learned something is simple: can I explain it clearly enough for someone else to try?

That’s why I keep [哥斯拉笔记 · Godzilla Notes](https://scudlen7.github.io/godzilla-blog/). It’s my second brain for study notes, bugs I’ve worked through, and technical experiments that were too much fun to leave on my hard drive.

## What I’m building

My blog starts with a Markdown file. Astro turns it into a page, Pagefind makes the text searchable, and GitHub Actions publishes it to GitHub Pages when I push to `main`. You can switch between Chinese and English while reading the same post.

- **Read the [first post](https://scudlen7.github.io/godzilla-blog/posts/hello-world/)** for a quick tour of how I write and format my notes.
- **Explore the [blog source](https://github.com/Scudlen7/godzilla-blog)** to see how the pieces fit together.
- **Share a [guest post](https://scudlen7.github.io/godzilla-blog/contribute/)** if you have a useful fix, a learning note, or an experiment of your own.
